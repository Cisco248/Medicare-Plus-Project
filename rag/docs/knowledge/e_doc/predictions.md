# E-Doc Predictions

## Question: What does my prediction mean?

### Answer

It is the output class of a machine-learning model given the submitted features. It is educational risk communication. It is not a diagnosis, prescription, or emergency triage.

## Question: Is a high-risk prediction a diagnosis?

### Answer

No. A machine-learning prediction is not the same as a clinical diagnosis. Laboratory tests, repeated blood-pressure measurements, or cardiology assessment may still be needed.

## Question: Why did my prediction change?

### Answer

Different typed numbers, different checkboxes, or a different model form will change the feature vector. Unit mistakes (glucose 180 in a mmol/L field) can also change it.

## Question: Can incorrect input change the prediction?

### Answer

Yes. The models use the numbers they receive.

## Question: What happens if one parameter is abnormal?

### Answer

The classifiers use multiple features together. One unusual value can shift probability but does not automatically establish disease. One typical value does not guarantee safety.
