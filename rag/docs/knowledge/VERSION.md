# Knowledge Base Version

## Current release

- Version: 1.0.0
- Release date: 2026-08-18
- Content access date: 2026-08-18

## Scope

Version 1.0.0 provides general educational material for RAG retrieval about diabetes, hypertension, cholesterol, physical activity, sedentary behavior, sleep, monitoring, and safety escalation. It includes rules for interpreting clinical, self-reported, and wearable data without turning associations or trends into diagnoses.

The release does not provide individualized treatment plans, medication recommendations, diagnostic decision rules, or country-specific emergency numbers.
